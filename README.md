# README.md

本项目是一个用于展示与承载二次创作系列 《乐队子世代：那美好的未来》 的前端静态网站。



### ✨ 项目简介

《乐队子世代：那美好的未来》是基于 **《BanG Dream! It's MyGO!!!!!》** 与 **《BanG Dream! Ave Mujica》** 的二次创作子世代世界观设定，时间线位于原作结局二十余年后。

本网站作为该系列的 **统一展示与整理平台**，用于：

- 世界观与设定的集中呈现
- 人物关系、称呼表、亲缘谱的可视化展示
- 小说、文本类内容的长期收录
- 作为公开、可访问的静态内容站点部署



### 🛠 技术栈

- **框架**：Vue 3
- **语言**：TypeScript
- **构建工具**：Vite
- **路由**：Vue Router
- **样式方案**：Scoped CSS
- **部署方式**：GitHub Pages（静态托管）



### 🔐 隐私与内容说明

本项目为 **非商业、展示性质网站**。

- 不收集访问者的个人信息
- 不包含用户登录、评论、追踪等功能
- 若页面中出现署名、签名或创作者内容，均基于明确同意或匿名展示

如有内容需要修改或撤下，请通过项目主页提供的联系方式进行反馈。



### 🚀 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

### 🥚小细节

1. 立希的个人详情页的URL：`band-next-gen/#/char-detail/rikki`，结尾不是“taki”,而是“rikki”
2. 子世代9人的个人详情页的FAMILY RELATIONS的部分，都是先写母系母亲，再写父系母亲，比如莉子的个人详情页里先写了海铃，再写了立希，而美铃则先写立希，再写海铃。
3. 在「关系 → 亲缘谱」中，雫、灯、乐奈之间的连接线是虚线，因为雫是收养的，所以和亲生母女的连线有所区别。
